# Rust Extension

The compiled Rust extension (`open_cpap_parser._rust_parsers`) is built from `src/lib.rs` using [PyO3](https://pyo3.rs) and [Maturin](https://www.maturin.rs).

It exposes the following functions to Python:

| Function | Description |
|---|---|
| `parse_devilbiss(path, /)` | Parse a DeVilbiss IntelliPAP directory |
| `can_handle_devilbiss(path, /)` | Fingerprint a DeVilbiss directory |
| `parse_bmc(path, /)` | Parse a BMC / 3B Medical directory |
| `can_handle_bmc(path, /)` | Fingerprint a BMC directory |
| `parse_apex(path, /)` | Parse an Apex Medical directory |
| `can_handle_apex(path, /)` | Fingerprint an Apex Medical directory |
| `parse_lowenstein(path, /)` | Parse a Lowenstein / Weinmann directory |
| `can_handle_lowenstein(path, /)` | Fingerprint a Lowenstein directory |
| `parse_fisher_paykel(path, /)` | Parse a Fisher & Paykel SleepStyle directory |
| `can_handle_fisher_paykel(path, /)` | Fingerprint a Fisher & Paykel directory |
| `parse_yuwell(path, /)` | Parse a Yuwell / DJMed BreathCare directory |
| `can_handle_yuwell(path, /)` | Fingerprint a Yuwell directory |
